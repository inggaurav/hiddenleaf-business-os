# Communication Data Model — Comparison & Decision

**Target**: `hiddenleaf-business-os`  
**Branch**: `develop/hiddenleaf-v2`  
**Date**: 2026-08-15  

---

## 1. Comparison Matrix

| Domain Capability | Gideon Social Inbox | WorkDo Messenger | Final Unified Domain Decision |
|---|---|---|---|
| **Account Representation** | `ConnectedAccount` model with provider credentials | None (Internal Users only) | **`CommunicationAccount`**: Multi-tenant provider accounts (Gmail, WhatsApp, Slack, Meta, LinkedIn, TikTok, X, Internal). |
| **Conversation Aggregation** | Thread by external post/comment ID | Pairwise `from_id` / `to_id` in `ch_messages` | **`CommunicationConversation`**: Unified thread with provider thread ID, subject, unread count, status, assignment, and linked CRM entity. |
| **Message Storage** | `SocialInteractionModel` | `ch_messages` (`body`, `seen`, `attachment`) | **`CommunicationMessage`**: Canonical message with direction (`inbound`/`outbound`), delivery status, raw/text content, sent/read timestamps, and idempotency key. |
| **Participant Identity** | `author_name`, `author_handle` | Eloquent `User` | **`CommunicationParticipant`**: Deterministic identity with email, normalized phone, provider ID, display name, and CRM entity link. |
| **Urgency & Classification** | `AttentionPriorityCalculator` (0-100) & `InteractionClassificationEngine` | Boolean `seen` | **Gideon Model**: Adopt deterministic 0-100 priority scoring and intent classification for all channels. |
| **Drafting & Approvals** | `SocialReplyDraftModel` + Brand Profile | None | **Unified Model**: Draft replies generated by Mr. Fox using `MrFoxBrandProfile` + `ContentReviewEngine` + approved execution gate. |
| **Internal Messenger Integration** | Separate module | Existing `ch_messages` | **`InternalMessengerProvider`**: Adapter mapping `ch_messages` seamlessly into the Unified Inbox without modifying legacy tables. |

---

## 2. Decision Summary

- Build **one canonical communication domain** (`App\Domain\Communications\*`) with relational persistence:
  - `comm_accounts`
  - `comm_conversations`
  - `comm_messages`
  - `comm_participants`
  - `comm_attachments`
- Adapt **Gideon's** deterministic classification, urgency scoring, and brand draft generator.
- Integrate **WorkDo Messenger** via an adapter (`InternalMessengerProvider`) ensuring 100% WorkDo parity is preserved.
- Build native official providers for **Gmail API (OAuth + incremental sync)**, **WhatsApp Cloud API (HMAC webhook + templates)**, and **Slack API (OAuth + events)**.
- Wire **Mr. Fox intelligence tools** directly into the unified communication domain.
