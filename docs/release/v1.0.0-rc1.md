# Release Notes — HiddenLeaf Business OS v1.0.0-rc1

## Overview
HiddenLeaf Business OS v1.0.0-rc1 is the initial production Release Candidate, unifying complete enterprise ERP operations, autonomous intelligence, governed knowledge, and multi-channel customer communications into a cohesive operating system.

---

## What's New in v1.0.0-rc1

### 1. Executive Command Center & Intelligence Layer
* **Deterministic Business Health Scoring**: 0–100 mathematical health model evaluating Receivables, Payables, Cash, Sales, Inventory, Projects, Communications, and HR.
* **Executive Daily Briefing**: Period-over-period delta reporting and anomaly detection.
* **Evidence-Backed Recommendations**: Deduplicated actionable business recommendations linking directly to verified ERP records.
* **Global Command Palette (`Cmd+K`)**: Cross-domain search across leads, invoices, messages, tasks, and knowledge.

### 2. Autonomous Automations & Mr. Fox Missions
* **Event-Condition-Action Engine**: Zero-token deterministic rules for instant business event triggers.
* **Governed Mr. Fox Missions**: Goal-oriented multi-step AI execution bounded by tool allowlists and maximum step budgets.
* **Unified Approval Center**: Human-in-the-loop cryptographic authorization for high-risk sends and data modifications.

### 3. Unified Communications Inbox
* Unifies client interactions across **Gmail**, **WhatsApp Cloud API**, **Slack**, and **Internal Messenger**.
* Real-time attention priority scoring (0–100) and sentiment analysis.
* Tone-aligned automated reply drafting powered by tenant Brand Profiles.

### 4. Self-Service SaaS & Workspace Provisioning
* 6-step interactive Onboarding Wizard.
* Automatic transactional workspace provisioning with a 14-day free trial.
* 4 standard plan tiers (Starter, Growth, Business, Agency) with server-side limit enforcement.
* Built-in Demo Workspace Generator (`Load / Reset Demo Data`).

### 5. Production Hardening & Security
* Zero P0 security vulnerabilities; strict multi-tenant isolation.
* Liveness (`/health/live`) and Readiness (`/health/ready`) probes.
* `php artisan hiddenleaf:check` pre-flight diagnostic CLI command.
* Monotonic invoice document sequences backed by PostgreSQL pessimistic locking.
