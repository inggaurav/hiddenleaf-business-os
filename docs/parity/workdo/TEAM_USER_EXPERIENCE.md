# WorkDo Team User Experience Baseline

## 1. Role Scope & Gating
- A non-owner team member (e.g. Employee, Project Member, Sales Agent) only sees modules and menus explicitly permitted by their assigned Role / Permissions.
- Unauthorized modules (e.g. Accounting, Billing/Plans, System Settings, SuperAdmin controls) are strictly omitted from both sidebar and command navigation.

## 2. Typical Visible Navigation
- **Dashboard**: Global overview or assigned workspace dashboard.
- **Projects**: Only assigned projects, tasks, kanban boards, timesheets.
- **HRM (Self-Service)**: My Attendance, My Leave Requests, My Payslips, My Documents, Company Holidays & Announcements.
- **CRM**: Assigned Leads, Assigned Deals, Discussions, Task follow-ups.
- **Collaboration**: Messenger, Media Library.
